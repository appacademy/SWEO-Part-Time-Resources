# It's been a week since the schedule rollout, and we've heard some feedback

We want to support you in this new schedule as best we can, so...

## Starting this week, we'll be hosting pairing in zoom at the start of class

- Show up at 2:30pm or 7pm PST (5:30pm or 10pm EST)
- Once everyone shows up (~10m), we'll create pairs in Student Home and open breakout rooms
- **Remember, this pairing is optional, so don't attend if you don't want to pair**

## As a reminder, increased flexibility does NOT mean less instructional time

We encourage you to not think of this change like:

" I only have to show up 1 hour per day "

Instead, think of it like:

" I won't get penalized if I can't show up for 3 hours on any given day "

If you wish to succeed at a/A, you NEED to be putting in more than 3 hours of work per day.

That's still true in this new schedule, but you get to choose when those 3 hours take place!

We are still here the entire day! That's 2:30pm - 10pm PST, so make sure to get the help you need!
